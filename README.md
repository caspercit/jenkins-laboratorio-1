# Laboratorio 1 - Jenkins

## Objetivo
Instalar Jenkins mediante Docker y ejecutar
una tarea automatizada.

## Herramientas
- Docker Desktop
- Jenkins
- Git y GitHub

## Implementación
1. Se creó un volumen llamado jenkins_home.
2. Se ejecutó Jenkins mediante Docker.
3. Se configuró el usuario administrador.
4. Se creó una tarea Freestyle: pipe-hola-mundo.
5. Se agregó un paso Execute shell.
6. Se ejecutó el comando echo "Hola Mundo".

## Resultado
La tarea se ejecutó correctamente en Jenkins.
